# 超氚带场重建玩具测试（2026-09-29）

本包实际运行 v0.6.2 的独立 C++ 核心，不需要 ROOT 或 CEE 环境。
测试衰变为 $^3_\Lambda H\to{}^3He+\pi^-$，电荷依次为 +1、+2、−1。
两张主图是 `output/mass_before.png` 和 `output/mass_after_S.png`。

## 先看结论

- 同一批 5410 个真信号：质量 RMS 为 2.692 → 2.650 MeV/c²，改善约 1.59%（配对 bootstrap 统计误差约 0.23 个百分点）。
- 仅仅把 S 加入状态但不使用新的约束，不变质量完全不变。
- 第二张图还要求 PV χ²/ndf < 5（ndf=2）以及 S/σS > 3。相对于第一张图，保留 88.78% 信号和 2.75% 本底。
- 注入质量 ±6 MeV/c² 窗内，信噪比为 0.499 → 16.53。这一提升来自所选的玩具本底与拓扑筛选，不能当作 STAR 或 CEE 的实际性能预测。
- 未施加母粒子质量约束，也未以已知寿命约束候选。真值标签只用于分开画信号和本底，以及性能统计；任何重建选择均不使用真值标签。

## 原版代码和本次扩展的边界

`vendor/CEErco/CeeV0Lite` 中的源码保持与提供的 v0.6.2 一致。
原代码包 SHA256：`f0d2659cee9bbe6c93a0595c123f5f33282758afecb8d0892a20a309f15fab57`。

`core_bridge.cxx` 直接调用原来的 `VertexFitter::Fit()` 与
`VertexFitter::RecalculateMotherCovariance()`，后者包含原来的 24 次扰动重拟合。
子轨迹仍由原版 By 输运与最近点算法处理。传入的是物理动量 p，氦三电荷为 +2，不能把刚度 p/2 当作 p。

原版 `FitProductionVertex()` 明确拒绝非零母粒子电荷；原版高层 `Finder`
也没有超氚物种配置。因此本测试直接使用通用的两轨顶点核心，
并在 `charged_topology.py` 新增了均匀 By 下的带电母粒子 PV 约束。
这不是“未修改的 v0.6.2 已支持超氚”的验收结果，也没有修改用户的正式代码包。

## 输入及证据

| 输入 | 本次取值 | 性质与依据 |
|---|---|---|
| 碰撞动量谱 | STAR Au+Au 3 GeV，0–10%，−0.25 < yCM < 0 | STAR PRL 128, 202301 (2022)，补充材料 Fig. 4(a) 红色系列的 mT 指数拟合曲线 |
| 动量谱形状 | dN/dpT ∝ pT exp[−(mT−m)/T]，T ≈ 0.27969 GeV | 从官方论文 PDF 的矢量曲线坐标恢复；不是 HEPData 数值表。曲线恢复的最大 log10 偏差约 0.00013 |
| 抽样区域 | 0.3 < pT < 4 GeV/c；yCM 在上述窄区间内均匀，φ 均匀 | 包含已发表拟合曲线向未测区的外推；忽略流各向异性 |
| 实验室 boost | yboost=+1.045913 | 3 GeV 固定靶运动学，选定束流沿 +z；不是照搬 STAR 的坐标正负号 |
| 注入质量 | 2.99131 GeV/c² | 固定玩具真值，用于生成和比较，未输入母粒子质量约束 |
| 寿命 | 223 ps | 上述论文补充材料中单独 3 GeV 的结果中心值 |
| 磁场 | B=(0,+0.5,0) T | CEE 的 y 轴约定，非 STAR 的 z 轴磁场几何 |
| TPC 动量 | 见下方分辨率公式 | 参照 STAR 公开的百分之几量级；系数是玩具参数，非 3 GeV 氦三 embedding 标定 |
| TPC 参考点位置 / 方向 | 0.08 cm / 2 mrad | 各向同性的高斯玩具假设，非 STAR 完整轨迹协方差表 |
| PV | 每坐标 0.05 cm | 玩具近似，按 STAR 亚毫米量级取值 |
| TOF | 每轨总时间 σ=100 ps；公共 t0 σ=30 ps | 100 ps 参考 STAR TOF 性能量级；公共/独立误差拆分是本测试假设 |
| TOF 路程 | 均匀 220–280 cm，路程测量 σ=0.20 cm | 简化几何假设 |
| 事件数 | 6000 信号、120000 个无关 He3–π 组合 | 为展示而定，不按真实亮度、分支比、产额或效率归一化 |

定义 R=|p|/|Z|（GeV/c），本次动量分辨率为

$$\sigma_p/p=\sqrt{0.020^2+(0.005R)^2+[0.006/(\beta R)]^2}.$$

这是一条描述低动量恶化和高刚度恶化的简单曲线。
STAR TPC 技术论文的 2% 最佳分辨率示例对应其特定 0.25 T 条件，
不能解释为这里这条公式已被该论文验证，尤其不能外推为氦三的精确分辨率。
参考点取为每条真轨道在 SV 后 20 cm 的状态，再对位置、动量加噪声。
在参考点构造 6×6 位置/动量高斯协方差；传播与重拟合后生成位置—动量相关项。
没有完整 hit simulation、材料能损/多重散射、空间电荷、真实接受度和核吸收模型。

TOF 在本测试里用于粒子假设的时间一致性，动量由 TPC tracking 提供。
对两子轨迹时间作差，消去信号共同的衰变时刻及 t0，再与各自
测量路程和 tracking 动量给出的飞行时间差比较，施加 3σ 选择。
因此没有用真衰变时刻修正数据，也没有把 TOF 误差再次独立加到 tracking 动量上。
没有模拟 dE/dx 或误 PID；He3、π 粒子假设预先指定。本次不测试 CEE 零场 TOF 反推动量的外层迭代。

## 本底与共同选择

本底 He3、π 由两次独立的超氚衰变抽样取各自单粒子分布后组合，
没有预设一个本底质量函数。其中 80% 将两轨生产点设在 PV，
20% 保留两个无关的位移生产点和各自时间。这是简单的 prompt/secondary 混合模型，
不是 STAR 测量的本底比例。改变该比例会显著改变第二张图的 S/B。

两张图共同要求：0.1 < |pπ| < 2 GeV/c；0.3 < |pHe| < 10 GeV/c；
上述 TOF 一致性；原版顶点与 24 次协方差重拟合成功；
两子轨 DCA < 1 cm、共同顶点 χ² < 10。

第一张图使用共同顶点拟合得到的七维母粒子质量。
第二张图使用八维 PV 约束副本的质量，并额外要求 χ²PV/2 < 5、S/σS > 3。
两图纵轴刻度不同，计数没有重新归一化。
`same_candidates_and_S_pull.png` 另给完全相同候选的质量比较，用来隔离“重新拟合”与“切掉候选”两种效果。

## 带电 S 约束

保留 x=(rD,pD,E,rP) 的十维测量先验及完整协方差 C；
tracking 没有使用 PV，所以本测试可令其输入交叉协方差为零。
S=Larc/|p| 为未知的总飞行参数。令 k=0.00299792458 q By，a=kS，有

$$r_D-r_P=A(S)p_D,$$

$$A(S)=\begin{pmatrix}\sin a/k&0&(1-\cos a)/k\\0&S&0\\-(1-\cos a)/k&0&\sin a/k\end{pmatrix}.$$

中心值使用螺线精确映射，协方差使用局部一阶导数；S 不是固定为真值。
对三维几何约束线性化后，解析消去一个自由 S，因此增加两个有效约束自由度。
所有迭代都相对于同一个输入先验，不重复使用 PV。输出为衰变端的
(x,y,z,px,py,pz,E,S) 和完整 8×8 协方差。
端点转换时位置和动量均随 S 更新，并保留 ∂/∂S 的相关项。
可得到带误差的 Larc=S|p|、ct=Sm；没有强制质量或寿命值。

## 验证与已发现的问题

`output/validation.json` 记录：

- 独立 SciPy “8 参数拟合 10 个测量量”广义最小二乘的 32 个信号对照，状态差 < 3×10⁻⁸ 个标准差，协方差的尺度化差 < 10⁻⁸。
- By→0 时与未修改的 v0.6.2 中性 PV 拟合一致。
- PV↔SV 端点的状态、完整协方差往返恢复到数值精度。
- 正负磁场、正负电荷（包括 |q|=2）、正负输运路程与独立洛伦兹力 ODE 积分一致。
- 只存储 S 而不施加 PV 约束时，质量改变量精确为零。

统计闭合并不完美，必须保留这项发现：

- 质量 pull 的均值约 0.021、标准差约 1.003。
- S pull 的中央 68% 半宽约 1.001，但全样本标准差为 1.192。
- 5410 个信号中有 9 个 |S pull|>5；对应衰变点明显偏离真值，存在长尾，疑似带场轨迹交点/局部解选择问题。未用真值删掉这些候选。
- 这些候选可能仍通过 PV χ² 与 S/σS 选择。因此图中的本底抑制不是“顶点一定正确”的证明。正式使用需要进一步处理顶点候选分支与真实探测器路程约束。
- 约束后的质量均值比注入质量高约 0.145 MeV/c²；本测试未进行质量偏差标定。
- 109706 个通过输入接受与 PID 的组合中，原顶点迭代失败 671 个，输运失败 3 个，母粒子协方差扰动重拟合失败 15 个。计数在 `config.json`；不保留失败候选的伪误差。

以上使本包适合算法演示和问题定位，不能当作带电超氚正式重建版本。

## 重现

需要 Linux g++（OpenMP）、Python 3、numpy/scipy/matplotlib。无需 ROOT/CEE。

```bash
bash build.sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=4 python3 simulate.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=4 python3 validate.py
OPENBLAS_NUM_THREADS=1 python3 plot_results.py
```

固定随机种子为 20260929。完整协方差中间文件 `candidates.npz` 约 82 MB，
压缩包没有包含它；运行 simulate.py 即可重新得到。
已包含逐候选结果 CSV、分箱质量谱 CSV、图、参数、验证结果及源码。
